## Scope & Constraints

**In scope:**  
All modules under `src/drunk_ai_proxy/drunk_ai_proxy/` across packages `app`, `auth`, `middleware`, `proxies`, `utils`.

**Out of scope:**  
Test fixture/mock rewrites not directly caused by production-side changes; `drunk_ai_client`; `data/`; CI infrastructure (beyond what import-linter already validates).

**Hard constraints (from `AGENTS.md` / `copilot-instructions.md`):**
- One primary class per module; zero module-level business logic (P0 — non-negotiable).
- All state in `self._attr`; no mutable module-level globals.
- Google-style docstrings on all public classes/methods.
- Python 3.10+ syntax: `X | Y` unions, `list[T]`/`dict[K,V]`, `match/case`.
- Pydantic v2 only (`model_config = ConfigDict(...)`, no inner `class Config`).
- No `Optional` — use `X | None`; no `Any` unless justified with comment.
- Logging: module-level `logger = logging.get_logger(__name__)`; log only `type(e).__name__`.
- Sensitive values truncated to last 4 chars in logs.
- Default to incremental, compatibility-preserving refactors.

#### Task 2.1 — Extract `_attach_resource` helper in `McpProxyProvider`
**Finding:** F-DRY-01 / P2-01  
**Files:** `proxies/mcp/proxy_provider.py`  
**Action:**
1. Identify the common structure shared by `_add_skill_proxy`, `_add_remote_skill_proxy`, `_add_prompt_proxy`, `_add_remote_prompt_proxy`, `_add_agent_proxy`, `_add_remote_agent_proxy`.
2. Extract private method:
   ```python
   def _attach_resource(
       self,
       mcp: FastMCP,
       resource_type: str,
       dirs: list[str],
       provider_factory: Callable[[McpConfig, list[str]], object],
       register_fn: Callable[[object, FastMCP], int],
   ) -> None:
       valid_dirs = self._validate_resource_directories(dirs, resource_type)
       if not valid_dirs:
           return
       try:
           provider = provider_factory(self.config, valid_dirs)
           count = register_fn(provider, mcp)
           logger.info(
               "Registered %d %s(s) for path '%s'",
               count, resource_type, self.config.path,
           )
       except Exception as e:
           logger.error("Failed to attach %s for path '%s': %s", resource_type, self.config.path, type(e).__name__)
           audit_log(logger=logger, event=f"mcp_{resource_type}_provider_failed", status="failure", resource=self.config.path, details={"error_type": type(e).__name__})
   ```
3. Refactor all six `_add_*_proxy` methods to delegate to `_attach_resource`.
4. Update unit tests if they tested the duplicate pattern directly.

**Expected delta:** ~−120 lines, +30 lines net ~−90 lines.

**Acceptance criteria:**
- `python -m pytest tests/test_mcp_proxy_provider.py tests/test_mcp_proxy_provider_extended.py -q` passes.
