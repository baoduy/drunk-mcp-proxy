    self,

### Priority 4 — Reusable Abstractions: Dependency Inversion for `proxies` and `auth`

This resolves both `import-linter` violations by introducing lightweight Protocol interfaces.

| # | Issue | Evidence | Proposed Change | Expected Gain | Effort | Risk |
|---|-------|----------|-----------------|---------------|--------|------|
| P4-A | `proxies → app` (base_provider) | `McpBaseProvider._get_app_auth_provider()` calls `AppConfigProvider.get_instance()` | Inject `auth_provider_factory: AuthProviderFactory \| None` into `McpBaseProvider.__init__` via Protocol | Removes violation; testable without app singleton | M | Low |
| P4-B | `proxies → app` (llm proxies_provider) | `LlmProxiesProvider.__init__` imports `AppConfigProvider` + `CacheProvider` | Inject `auth_provider_factory` + `cache: TTLAsyncKeyValue` via constructor; `app/server.py` passes concrete instances | Same as above | M | Low |
| P4-C | `auth → app` (httpx_oauth_base) | `httpx_oauth_base.py` live-imports `CacheProvider` at module level | Remove module-level import; `token_storage` parameter already exists — make the live `CacheProvider` reference local/lazy OR pass via caller | Removes violation | S | Low |

**Protocol definitions (new file `utils/protocols.py`):**
```python
"""Shared Protocol interfaces for cross-layer dependency inversion."""

from __future__ import annotations

from typing import TYPE_CHECKING, Protocol

if TYPE_CHECKING:
    from drunk_ai_proxy.utils.config_yaml import AuthType


class AuthProviderFactory(Protocol):
    """Interface for creating FastMCP auth providers."""

    def get_fast_mcp_auth_provider(
        self,
        provider_name: "AuthType | None" = None,
    ) -> object | None: ...


class TokenStore(Protocol):
    """Interface for asynchronous key-value token storage."""

    async def get(self, key: str) -> object | None: ...

    async def set(
        self,
        key: str,
        value: object,
        ttl_seconds: int | None = None,
    ) -> None: ...
```

**`McpBaseProvider.__init__` updated signature:**
```python
def __init__(
    self,
    config: McpConfig,
    auth_factory: AuthProviderFactory | None = None,
) -> None:
```

**Wiring point (app/server.py):**
```python
provider = McpProxyProvider(config, auth_factory=AppConfigProvider.get_instance())
```

### Priority 5 — Long-Horizon: Split `AppConfigProvider` (coordinated change)

| # | Issue | Evidence | Proposed Change | Expected Gain | Effort | Risk |
|---|-------|----------|-----------------|---------------|--------|------|
| P5-A | God object | `AppConfigProvider`: 3 responsibilities in 1 class | Split into `AppConfigProvider` (config reader only) + `AuthProviderRegistry` (FastMCP factory) + `ClientAuthHandlerFactory` (httpx factory) | OCP; smaller test surface per class | L | Med |

**`AuthProviderRegistry` design sketch:**
```python
class AuthProviderRegistry:
    """Registry mapping AuthType → FastMCP auth provider factory."""

    _registry: dict[AuthType, Callable[..., AuthProvider]] = {
        AuthType.BASIC: lambda **cfg: ApiKeyAuthProvider(**cfg),
        AuthType.AZURE: lambda **cfg: AzureProvider(**cfg, client_storage=CacheProvider.get_oauth_store()),
        # ... one entry per AuthType
    }

    @classmethod
    def create(cls, name: AuthType, config: dict[str, object]) -> AuthProvider:
        factory = cls._registry.get(name)
        if not factory:
            raise ValueError(f"Unsupported auth type: {name}")
        return factory(**config)
```
